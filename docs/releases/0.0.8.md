# Captura 0.0.8

This release rebuilds the capture editor, adds Trash, and makes every write and
every keystroke cheaper.

## Captures are a page now

- Opening a capture shows one editable page, Notion style. Type `/` for a block
  palette: text, headings, bullet and numbered lists, to-do lists, quotes, code
  blocks and dividers. Markdown shortcuts (`#`, `-`, `1.`, `>`, ``` ``` ```, `**`)
  work as you type.
- Edits save automatically a moment after you stop typing, and always before the
  page closes or moves to the next capture. A dialog appears only when a save
  fails.
- A Source view shows the same Markdown in a CodeMirror editor with highlighting
  and list continuation. Markdown stays the record: the page never rewrites a
  capture until you edit it there, and captures the page cannot represent
  faithfully (tables, raw HTML, images, setext headings) open in Source with a
  one-click way back.
- Trashed captures open read-only with a Restore button. Image captions still
  edit in place.

## Trash

- Delete moves captures to Trash, the trailing tab in the filter row, with an
  Undo toast. Restore or Delete now per capture, or Empty trash.
- Auto-delete after 7 days by default; Settings offers Now (no Trash), 7 days or
  28 days. Merged captures also go to Trash, so a merge can be undone.

## Queue

- `⌘A` selects every visible capture. Escape clears a multi-selection before it
  closes the panel. Select all is also in the context menu.
- Settings and captures open as full pages inside the panel, not as cards over
  a dimmed backdrop. Settings is organised into General, Shortcuts, Editor,
  Trash and About; its section highlight slides between tabs and each section
  slides in from the side it comes from.
- The composer grows a line at a time as a draft gains lines (Return or
  Shift+Return), from two lines up to five, and the queue gives up the space.
  Past five lines the field scrolls.
- New motion: pages push in over the queue and slide back out the same way on
  close; menus, the slash palette and toasts enter and leave; new captures slide in; the filter and composer underlines
  slide between tabs. Buttons have no hover effects and never lift or bounce.
  Reduced motion keeps the fades only.
- New typeface: Instrument Sans for the interface and captures, JetBrains Mono
  for Source, times and key caps. Both ship inside the app; nothing is fetched.
- New layout: an editorial header with the wordmark and a status line, a
  full-width search bar, a composer card with the capture kind as tabs,
  text filter tabs, section chips with counts, and two-line rows with the
  time leading the meta line.
- Type scale and controls are tokenised; nothing on screen is smaller than 10 px.

## Fixes

- The grey square behind the panel's rounded corners while Settings was open
  is gone. The dimmed, blurred backdrop reached the window's transparent
  corners and painted the webview's light-mode under-page colour there; pages
  now live inside the panel's rounded clip and need no backdrop.
- The panel no longer closes after adding an image when "Keep Captura open" is
  off. The image chooser now hands focus back to the panel instead of replaying
  a click-away hide, and the capture HUD no longer takes focus.

## Faster

- Writes no longer wait for a database backup. Backups run on their own thread,
  coalesced per burst of writes, after every settings change, and on quit or
  when the panel hides; the launch backup runs after the app is up and only when
  something is pending.
- SQLite: WAL with `synchronous=NORMAL`, memory temp store, larger cache,
  memory-mapped reads, cached prepared statements, `RETURNING` writes, one
  transaction per bulk action, new indexes on `created_at` and `deleted_at`,
  and a checkpoint on exit so the WAL stops growing between launches.
- Bulk delete and mark-done are one call each. Queue rows are memoized and
  receive stable handlers, search is deferred and cached, and a mutation no
  longer renders the list twice.
- Measured numbers are in `docs/performance/0.0.8.md`.

## Download and update

Download `Captura_0.0.8_aarch64.dmg` for Apple Silicon Macs running macOS 13 or
later. Existing installations can use Check for updates in Settings. The app is
signed with the existing Captura Dev identity and is not Apple-notarized.

Captures, images, sections, settings, backups and diagnostics stay local. The
database migrates in place (schema version 6) and remains readable by the
backup tooling from 0.0.6.
