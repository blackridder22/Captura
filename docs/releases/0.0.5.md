# Captura 0.0.5

This update brings the improvements since 0.0.3 into Captura's existing menubar
panel.

- Double-click a capture to read the complete Markdown in a centered overlay.
- Use the pencil to open a centered editor with Source and Preview tabs.
  Unsaved drafts are protected, and closing returns to the same queue position.
- Section menus and their delete confirmations are compact and stay inside the
  panel. Deleting a section keeps its captures in Unfiled.
- Add images through Choose images or Paste image, alongside the existing
  clipboard shortcuts. Background imports retain full-resolution originals and
  create smaller queue thumbnails.
- PNG, JPEG, TIFF, HEIC, WebP, GIF, and BMP are supported. Batch imports report
  individual failures and explain when only the first frame is captured.
- Failed Quick Capture saves retain the draft, show an error, and allow retry.
  Repeated submissions while saving are ignored. If section assignment fails
  after saving, the capture remains available in Unfiled.
- Quick Capture preserves the original Markdown indentation, trailing spaces,
  and line breaks.

## Download and update

Download `Captura_0.0.5_aarch64.dmg` for Apple Silicon Macs running macOS 13 or
later. Existing installations can use Check for updates in Settings. The release
includes `Captura.app.tar.gz`, its updater signature, and `latest.json`.

The app uses the existing Captura Dev signing identity and is not Apple-notarized.
macOS may require approval in System Settings > Privacy & Security on first launch.

Captures, images, sections, and settings remain local. The data directory and
updater signing key are unchanged from 0.0.3.
