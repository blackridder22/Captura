# Captura 0.0.6

This release protects saved captures if Captura's primary data directory goes missing.

- Captura keeps a separate local SQLite backup, including committed WAL data and image attachments, in `~/Library/Captura Backups`.
- On startup, Captura restores a missing database from a valid backup. If recovery is unsafe, it pauses saving and shows a warning instead of overwriting the backup.
- A local diagnostic log in `~/Library/Logs/Captura/diagnostics.jsonl` records database writes, backup results, startup file checks, and observed exits. It does not include capture text.

The log starts recording after this version launches; it cannot explain data loss that happened earlier. An abrupt shutdown may not produce an exit entry, but the next launch records that the previous exit was unobserved.

The Apple Silicon DMG supports macOS 13 or later. The app is signed with the existing Captura Dev identity and is not Apple-notarized. Captures, backups, and diagnostics stay local.
